Mounting Concept for Series 318 DMD - FQS Package

This mounting information provides a reference concept for mounting the DLP301S DMD.
The DLP301S (0.3 3.6MP 3D-Printing) DMD utilizes the FQS package and is a Series 318 DMD.
This mounting concept is for all Series 318 DMDs.
  • Information includes:
    • DMD 3D-CAD geometry model (STEP format)
    • Link to DMD mechanical drawing - located at end of DMD data sheet
    • Link to DMD data sheet (contains information like)
      • Mounting and thermal load specifications
      • Thermal specifications
      • Array temperature calculation
    • Electrical interconnect - mating connector information along with suppliers known at time of publishing
    • Mechanical mounting concepts - has drawings (pdf format) and 3D-CAD geometry model (STEP format) for parts and assembly
Getting Started
Easy access to the files is provided with a web browser interface.
Use of the web interface requires the files be downloaded and extracted to the computer.

To utilize the web interface:
  1. Open the file 'READ-ME-s318-Mounting.htm'    (this file)
  2. 'Right Click'   on the downloaded file name and select   ' Extract All...'
          (Note:   Picking the file name will open the file but not extract the files)
  3. Select a destination to extract the files and select   'Extract'
  4. After extracting pick this link   REVIEW_START-Series318.html   or image below to start review
(If the above link does not open the file or an image does not display below repeat Step (1) to extract the files)
